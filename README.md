# Eric Perspective

一个从个人思考和表达方式中提炼的实验性 AI skill，用来在讨论、战略判断、生活选择或写作时，尝试采用 Eric 的视角。

它从具体问题和真实使用场景出发，关注对象之间的关系、机会成立的条件，以及不同选择的代价。闲聊时自然接话；正式写作随读者和用途调整表达。

**这是有限材料上的模拟，不代表本人全部观点，也不能替代本人判断。** 新话题中的观点是模型推演，并非 Eric 真实发表的看法。当前版本仍在校准，尚未证明能稳定复现本人思维或文风。

## 使用

将本仓库克隆到 Codex skills 目录中的独立文件夹，即可在新的会话中调用 `eric-perspective`。如果同名目录已存在，请先检查并保留现有版本，使用其他目录或按需手动比较，不要直接覆盖。

```bash
git clone https://github.com/Eric-Cqc/eric-perspective.git <目标目录>/eric-perspective
```

例如：“用 Eric 的视角分析这个选择”“用 Eric 的方式和我聊聊这个问题”。技能是否自动触发和实际效果取决于使用环境与请求；可明确指定技能调用。

## 隐私和来源

公开版本只提供经过整理的通用方法，不包含私人对话原文、对话标识、工作或生活经历、设备路径及密钥。个人视角本身是有选择的抽象，不应据此推断用户未表达过的经历、动机或立场。
